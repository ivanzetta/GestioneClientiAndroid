# Versione 0.8.0 — modifiche

- Migrazione SQLite 1→2 non distruttiva: due email.
- Modifica/visualizzazione email e esportazione Excel.
- Import Excel vecchio: email facoltative e i valori email già salvati non vengono sovrascritti se colonne assenti.
- Backup vecchio compatibile (email vuote), nuovo backup include email.

- Icona approvata.

**Attenzione**: creare un backup dall'app prima di installare. La firma APK deve corrispondere a quella installata: non disinstallare senza backup.

**Outlook**: l'apertura diretta dell'editor evento dipende dalla versione dell'app; se non disponibile si tenta il calendario Android. L'evento viene salvato solo quando l'utente conferma.
